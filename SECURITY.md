# Security policy for Netchecks

## Report privately

Use [Report a vulnerability](https://github.com/CamiloSar/netchecks-security/security/advisories/new) to send a private report to the repository owner. A GitHub account is required. No public email address is provided.

Include the affected Netchecks URL, browser/device and application version when available, a description of the impact, and minimal steps to reproduce. Redact personal information. Never attach passwords, tokens, personal connection history, private support reports, or other people's data.

## Scope

This channel covers the current production Netchecks web application at https://netchecks.app, including its browser storage, offline behavior, monitoring and optional tools. Application source is maintained separately and is not published in this repository.

Cloudflare, GitHub, ipify, and other third-party services are outside this application's scope. Report issues in those services to their respective security teams.

## Responsible reporting

Use only accounts, devices and data you control. Stop if you encounter someone else's information. Do not run denial-of-service tests, mass scans, credential attacks, social engineering or destructive tests. Please coordinate disclosure with the owner so the issue can be investigated before exploit details are published.

This policy and the site's security.txt do not authorize intrusive testing, grant legal safe harbor, promise a response deadline, or offer a reward. Ordinary product feedback should not be submitted as a security vulnerability.

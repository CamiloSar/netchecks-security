# Netchecks security reports

This repository contains the public security reporting policy for [netchecks.app](https://netchecks.app). It does not contain application source code.

Report suspected vulnerabilities through [GitHub's private reporting form](https://github.com/CamiloSar/netchecks-security/security/advisories/new). A GitHub account is required. Do not put vulnerability details in public issues, discussions or pull requests.

Read [SECURITY.md](SECURITY.md) for scope and reporting guidance. This is a reporting channel, not an open-source release or a paid bug bounty program.
